Export Calendar to Outlook

Follow these steps to import this calendar into your Outlook:

  1. Make reservations for the device using the form above
  2. Click the "Export Calendar" button below to download the calendar file (.ics format)
  3. Open Outlook
  4. Go to the Calendar view
  5. For Outlook desktop: Select File > Open & Export > Import/Export > Import an iCalendar (.ics)
  6. For Outlook web: Select Add calendar > Upload from file
  7. Browse to the downloaded calendar file and open it
  8. Follow the prompts to complete the import

Once imported, you can view all device reservations in your Outlook calendar.
