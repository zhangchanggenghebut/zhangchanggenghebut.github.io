Use with Outlook Calendar

You have multiple options to add this calendar to your Outlook:

Webcal Subscription Link

Copy this link and add it as a subscribed calendar in Outlook:

This will create a live subscription that automatically updates.

How to Subscribe in Outlook

  1. Open Outlook and go to Calendar view
  2. For Outlook desktop: Right-click "Other Calendars" > "Add Calendar" > "From Internet"
  3. For Outlook web: Click "Add calendar" > "Subscribe from web"
  4. Paste the webcal:// URL and click "OK" or "Import"
  5. The MOKE reservation calendar will now appear and automatically update

How to Import ICS File

  1. Click the "Download Calendar (.ics)" button above to download the calendar file
  2. Open Outlook and go to Calendar view
  3. For Outlook desktop: Select File > Open & Export > Import/Export > Import an iCalendar (.ics)
  4. For Outlook web: Select Add calendar > Upload from file
  5. Browse to the downloaded calendar file and open it
  6. Choose whether to import as a new calendar or add to existing

Note: This creates a static copy. You'll need to re-download to get updates.
